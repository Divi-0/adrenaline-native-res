# Programs with a PSP-depth twin <stem>_pspdepth_<f|v> (scripts/shader-variants.sh, vita/src/shaders.rs embed_twin!):
# every program the PSP_DEPTH code changes. The untextured read programs have none (no depth code).
# After a stem: more defines for its twin. GE_FILTER: the textured fragment programs of the PSP-depth set
# also filter as the GE (core game_quirks.rs `PSP_DEPTH_GAMES`, DESIGN "fifty-ninth session"); not the dithered
# ones (God of War, the only game with this set, never dithers). GE_LIGHT: the lit vertex programs light in
# the GE's integer arithmetic (core lighting.rs GpuLights::ge_color, DESIGN "sixtieth session"); only those
# God of War's dumped scenes take (memory: ~0.6 KB each; the flat ones ~1.2 KB): the 3D one, the full raw one,
# lit1 / lit4 with 4444 or 8888 colours or any (generic), the point-light ones.
# GE_DEPTH: the raw vertex programs take the PSP depth from the GE's integer vertex arithmetic (core
# ge_math::integer, nativeres_raw_v.cg GE_DEPTH, DESIGN "sixty-first session"); only the raw programs God of
# War's dumped scenes take (replay REPLAY_RAW_VARIANTS): plain 8888 / 4444, plain4 8888, lit1 / lit4 8888 /
# 4444, the point-light ones and the full one. Others keep the float depth.
# NO_DEPTH (no define: a mark for the scripts): the GE_FILTER twins also WITHOUT the PSP depth, nativeres_x_nodepth_f,
# nativeres_x_nodepthwide_f (GE_WIDE) and nativeres_x_nodepthgather_f (GE_GATHER), for draws without depth test, which
# do not use the depth their program writes (vita/src/draw.rs `NO_DEPTH_TWINS`, DESIGN "seventy-sixth session"); only
# the frame-read programs God of War's draws without depth test take (its depth-of-field pass, bright pass and HUD),
# and the masked alpha test (the bright pass, without frame read since the eightieth session).
